## 🔐 Environment Configuration

If your application requires a GitHub Personal Access Token, create a `.env` file in the project directory.

Add the following configuration:

```text
GITHUB_TOKEN=your_github_token_here
```

Replace `your_github_token_here` with your own GitHub token.

Ensure your application loads the environment variable correctly. If required, install and configure `python-dotenv`.

**Security Notice:** Never upload your actual GitHub token, passwords, or `.env` file containing secrets to GitHub.

## 🔒 Security Best Practices

* Keep GitHub Personal Access Tokens private.
* Store sensitive credentials in environment variables.
* Add `.env` to `.gitignore`.
* Never commit passwords, API keys, or private credentials.
* Grant access tokens only the permissions required by the application.
* Review your repository before pushing files to GitHub.
